Kako povezati Booking.com i Airbnb

Sinkronizacija je već napisana i radi automatski, bez servera — pokreće je GitHub Action svaka tri sata. Postavlja se jednom, u pet koraka:

  1. Na Booking.com extranetu: Stopa i dostupnost → Sinkronizacija kalendara → Izvezi i kopirajte iCal link svakog apartmana.
  2. Na Airbnb-u: Kalendar → Dostupnost → Povežite kalendare → Izvezi kalendar i kopirajte link.
  3. U GitHub repozitoriju otvorite Settings → Secrets and variables → Actions → New repository secret, ime VE_ICAL_SOURCES, a vrijednost složite ovako: 
    {"a1":{"booking":"...","airbnb":"..."},
 "a2":{"booking":"...","airbnb":"..."},
 "a3":{"booking":"...","airbnb":"..."}}
  4. U kartici Actions pokrenite Sinkronizacija kalendara jednom ručno da provjerite radi li. Dalje ide samo, svaka tri sata.
  5. U suprotnom smjeru: adrese kalendar/a1.ics, a2.ics i a3.ics zalijepite na Booking.com i Airbnb kao vanjski kalendar, da i oni vide vaše termine.

Ako neki portal privremeno ne odgovori, kalendar zadrži zadnje poznato stanje i ovdje se pojavi upozorenje — nikad ne prikazuje slobodno ono što je zapravo zauzeto. Dok sinkronizacija nije postavljena, kalendar radi s terminima iz data.js i onima koje ovdje ručno blokirate.

Podaci se u demo verziji čuvaju u ovom pregledniku. Izvezite ih ako mijenjate uređaj ili brišete povijest pregledavanja.
